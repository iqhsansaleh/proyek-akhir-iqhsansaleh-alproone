# Generator Soal Latihan Aritmetika Dasar
Proyek Akhir Kelompok - Mata Kuliah Algoritma dan Pemrograman (S1 Pendidikan Matematika FKIP Untirta)

## Deskripsi Proyek
Program berbasis konsol (CLI) Python ini dirancang untuk membantu guru matematika atau siswa dalam menghasilkan latihan soal aritmetika (penjumlahan, pengurangan, dan perkalian) secara otomatis. Program ini dilengkapi dengan sistem validasi input, evaluasi jawaban secara *real-time*, perhitungan skor, serta penyimpanan laporan ke dalam file teks.

## Cara Menjalankan Program

1. Pastikan Anda telah menginstal **Python 3** di komputer Anda.
2. Buka folder repositori ini menggunakan **VS Code**.
3. Jalankan terminal terintegrasi di VS Code dan arahkan ke direktori `src/`:

```bash
cd src
python3 main.py
```

4. Ikuti instruksi interaktif yang muncul di terminal untuk memilih tingkat kesulitan dan jumlah soal.
